פרק 1: מספרים מרוכבים - הבסיס

חלק 1: הסיכום (Cheat Sheet)

הגדרה אינטואיטיבית: מספר מרוכב $z$ הוא הרחבה של המספרים הממשיים, המאפשרת הוצאת שורש למספרים שליליים. הוא מוגדר כ-$z = x + iy$, כאשר $x,y$ ממשיים ו-$i$ הוא היחידה המדומה המקיימת $i^2 = -1$. גיאומטרית, מספר מרוכב הוא נקודה (או וקטור) במישור דו-ממדי (מישור גאוס), שם ציר ה-$x$ הוא הממשי ($Re$) וציר ה-$y$ הוא המדומה ($Im$).

נוסחאות מפתח:

  • הצגות המספר:
    • אלגברית: $z = x + iy$
    • פולרית (קוטבית): $z = r(\cos\theta + i\sin\theta) = r \text{cis}\theta$
    • אקספוננציאלית (אוילר): $z = r e^{i\theta}$
  • מעברים: $r = |z| = \sqrt{x^2 + y^2}$ (מודול/ערך מוחלט), $\theta = \arg(z)$ (זווית/ארגומנט). מחושבת ע"י $\tan\theta = \frac{y}{x}$ (יש לשים לב לרביע!).
  • משפט דה-מואבר (De Moivre): חזקה: $(r \text{cis}\theta)^n = r^n \text{cis}(n\theta)$.
  • שורשים: הפתרונות למשוואה $w^n = z$ הם $n$ שורשים שונים: $$w_k = \sqrt[n]{r} \cdot \text{cis}\left( \frac{\theta + 2\pi k}{n} \right), \quad k = 0, 1, ..., n-1$$
  • צמוד קומפלקסי: אם $z = x+iy$, אז $\bar{z} = x-iy$. תכונה חשובה: $z \cdot \bar{z} = |z|^2 = x^2+y^2$.
אלגוריתם פתרון: מציאת שורשים ($z^n = w$)
  1. העברה: וודא שהמספר $w$ באגף ימין כתוב בהצגה פולרית ($r \text{cis}\theta$).
  2. זיהוי: זהה את רדיוס המספר ($r$) ואת הזווית שלו ($\theta$). זהה את סדר השורש המבוקש ($n$).
  3. הצבה: הצב בנוסחת השורשים.
  4. ריצה: הצב את האינדקס $k$ מ-$0$ ועד $n-1$ כדי לקבל את כל הפתרונות.
דוגמה פתורה

שאלה: פתור את המשוואה $z^3 = 8i$.

פתרון:

נעביר את $8i$ להצגה פולרית: $r=8$, הזווית היא $90^\circ$ (על הציר המדומה החיובי), כלומר $\frac{\pi}{2}$.
$$z^3 = 8 \text{cis}\left(\frac{\pi}{2}\right)$$ לפי הנוסחה: $$z_k = \sqrt[3]{8} \text{cis}\left(\frac{\pi/2 + 2\pi k}{3}\right) = 2 \text{cis}\left(\frac{\pi}{6} + \frac{2\pi k}{3}\right)$$ נציב $k=0,1,2$:

  • $k=0 \Rightarrow z_0 = 2 \text{cis}(\frac{\pi}{6}) = 2(\frac{\sqrt{3}}{2} + \frac{1}{2}i) = \sqrt{3} + i$
  • $k=1 \Rightarrow z_1 = 2 \text{cis}(\frac{5\pi}{6}) = 2(-\frac{\sqrt{3}}{2} + \frac{1}{2}i) = -\sqrt{3} + i$
  • $k=2 \Rightarrow z_2 = 2 \text{cis}(\frac{9\pi}{6}) = 2 \text{cis}(\frac{3\pi}{2}) = -2i$

חלק 2: התרגול (Drill)

תרגיל 1

נתונים המספרים $z_1 = 2+3i$ ו-$z_2 = 4-5i$. חשב את $z_1 \cdot z_2$ ואת $\frac{z_1}{z_2}$ (התוצאה צריכה להיות מהצורה $x+iy$).

כפל:
$z_1 \cdot z_2 = (2+3i)(4-5i) = 8 - 10i + 12i - 15i^2$
מכיוון ש-$i^2=-1$, נקבל: $8 + 2i + 15 = \mathbf{23 + 2i}$.

חילוק: (נכפול בצמוד של המכנה)
$\frac{2+3i}{4-5i} = \frac{(2+3i)(4+5i)}{(4-5i)(4+5i)} = \frac{8 + 10i + 12i + 15i^2}{16 - 25i^2}$
$\frac{8 + 22i - 15}{16 + 25} = \frac{-7 + 22i}{41} = \mathbf{-\frac{7}{41} + \frac{22}{41}i}$

תרגיל 2

כתוב את המספרים הבאים בהצגה פולרית ($r \text{cis}\theta$):
א. $z = -1 + i$
ב. $z = -5i$

א. $z = -1 + i$:
$r = \sqrt{(-1)^2 + 1^2} = \sqrt{2}$.
הנקודה $(-1, 1)$ נמצאת ברביע השני. $\tan\alpha = |\frac{1}{-1}| = 1 \Rightarrow \alpha = 45^\circ$.
ברביע השני: $\theta = 180^\circ - 45^\circ = 135^\circ = \frac{3\pi}{4}$.
תשובה: $\mathbf{\sqrt{2} \text{cis}\frac{3\pi}{4}}$.

ב. $z = -5i$:
הנקודה נמצאת על הציר המדומה השלילי (למטה).
$r = 5$.
$\theta = 270^\circ = \frac{3\pi}{2}$.
תשובה: $\mathbf{5 \text{cis}\frac{3\pi}{2}}$.

תרגיל 3

חשב באמצעות משפט דה-מואבר את $(1+i\sqrt{3})^{6}$.

המספר הוא $z = 1 + i\sqrt{3}$.
$r = \sqrt{1+3} = 2$.
$\theta$: רביע ראשון, $\tan\theta = \sqrt{3} \Rightarrow \theta = 60^\circ = \frac{\pi}{3}$.
לפי דה מואבר:
$z^6 = (2 \text{cis}\frac{\pi}{3})^6 = 2^6 \text{cis}(6 \cdot \frac{\pi}{3}) = 64 \text{cis}(2\pi)$
מכיוון ש-$\text{cis}(2\pi) = 1$, התשובה היא $\mathbf{64}$.

תרגיל 4

פתור את המשוואה $z^4 + 16 = 0$. שרטט את הפתרונות במישור המרוכב.

$z^4 = -16$.
נעביר לפולרי: $-16 = 16 \text{cis}(180^\circ) = 16 \text{cis}(\pi)$.
נוסחת השורשים: $z_k = \sqrt[4]{16} \text{cis}\left(\frac{\pi + 2\pi k}{4}\right) = 2 \text{cis}\left(\frac{\pi}{4} + \frac{\pi k}{2}\right)$.
הפתרונות ($k=0,1,2,3$):
$z_0 = 2 \text{cis}(\frac{\pi}{4}) = \sqrt{2} + i\sqrt{2}$
$z_1 = 2 \text{cis}(\frac{3\pi}{4}) = -\sqrt{2} + i\sqrt{2}$
$z_2 = 2 \text{cis}(\frac{5\pi}{4}) = -\sqrt{2} - i\sqrt{2}$
$z_3 = 2 \text{cis}(\frac{7\pi}{4}) = \sqrt{2} - i\sqrt{2}$
שרטוט: ריבוע שקודקודיו על מעגל ברדיוס 2, מסובב ב-45 מעלות.

תרגיל 5

מצא את המקום הגיאומטרי של הנקודות $z$ המקיימות את המשוואה: $|z - 2| = |z + 4|$. מהי המשמעות הגיאומטרית?

$|z - 2| = |z - (-4)|$.
גיאומטרית, זהו האנך האמצעי לקטע המחבר בין $(2,0)$ ל-$(-4,0)$.
אלגברית: נעלה בריבוע ונציב $z=x+iy$:
$(x-2)^2 + y^2 = (x+4)^2 + y^2$
$x^2 - 4x + 4 = x^2 + 8x + 16$
$-12x = 12 \Rightarrow \mathbf{x = -1}$
זהו ישר אנכי העובר ב $x=-1$.

תרגיל 6

פתור את המשוואה הריבועית (עם מקדמים מרוכבים): $z^2 - (2+i)z + (3+i) = 0$.

נוסחת השורשים:
$z_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
$b = -(2+i), \quad a=1, \quad c=3+i$
נחשב דלתא:
$\Delta = (2+i)^2 - 4(1)(3+i) = (4 + 4i - 1) - 12 - 4i = -9$.
השורש של הדלתא הוא $\pm 3i$.
פתרונות:
$z_{1,2} = \frac{2+i \pm 3i}{2}$
$z_1 = \frac{2+4i}{2} = \mathbf{1+2i}$
$z_2 = \frac{2-2i}{2} = \mathbf{1-i}$

תרגיל 7

הוכח את הזהות: $|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2(|z_1|^2 + |z_2|^2)$. (זהו "כלל המקבילית").

נשתמש בתכונה $|w|^2 = w \cdot \bar{w}$.
אגף שמאל:
$|z_1+z_2|^2 + |z_1-z_2|^2 = (z_1+z_2)(\overline{z_1+z_2}) + (z_1-z_2)(\overline{z_1-z_2})$
$= (z_1\bar{z}_1 + z_1\bar{z}_2 + z_2\bar{z}_1 + z_2\bar{z}_2) + (z_1\bar{z}_1 - z_1\bar{z}_2 - z_2\bar{z}_1 + z_2\bar{z}_2)$
האיברים המעורבים ($z_1\bar{z}_2$ וכו') מצטמצמים. נשארנו עם:
$= 2z_1\bar{z}_1 + 2z_2\bar{z}_2 = 2|z_1|^2 + 2|z_2|^2$. מ.ש.ל.

תרגיל 8

תהי המשוואה $(z-1)^3 = -8$. מצא את כל פתרונות המשוואה והראה שסכומם הוא 3.

נסמן $w = z-1$. המשוואה היא $w^3 = -8$.
$-8 = 8 \text{cis}(180^\circ)$.
שורשי $w$:
$w_0 = 2 \text{cis}(60^\circ) = 1 + i\sqrt{3}$
$w_1 = 2 \text{cis}(180^\circ) = -2$
$w_2 = 2 \text{cis}(300^\circ) = 1 - i\sqrt{3}$
כעת נמצא את $z$ (כי $z = w+1$):
$z_0 = 2 + i\sqrt{3}$
$z_1 = -1$
$z_2 = 2 - i\sqrt{3}$
סכום הפתרונות: $(2 + i\sqrt{3}) + (-1) + (2 - i\sqrt{3}) = 2 - 1 + 2 = \mathbf{3}$.

תרגיל 9

נתון התחום $D = \{ z \in \mathbb{C} \mid |z| < 1, \quad 0 < \arg(z) < \frac{\pi}{4} \}$.
שרטט את התחום $D$ ואת התחום המתקבל תחת ההעתקה $f(z) = z^3$.

התחום $D$: "פיצה" ברדיוס 1, זווית בין 0 ל-45 מעלות.
ההעתקה $f(z) = z^3$.
אם $z = r \text{cis}\theta$, אז $z^3 = r^3 \text{cis}(3\theta)$.
הרדיוס: $0 \le r < 1 \Rightarrow 0 \le r^3 < 1$ (נשאר מעגל יחידה).
הזווית: $0 < \theta < \frac{\pi}{4} \Rightarrow 0 < 3\theta < \frac{3\pi}{4}$.
תשובה: התחום המתקבל הוא גזרת מעגל היחידה הנפרשת בין הזוויות 0 ל-135 מעלות.

תרגיל 10

מצא את כל הפתרונות של המשוואה $z^6 = 1$. נסמן את הפתרונות ב-$w_0, w_1, ..., w_5$. חשב את הסכום $S = \sum_{k=0}^5 (1 + w_k)$.

השורשים $w_k$ הם שורשי המשוואה $z^6-1=0$.
סכום שורשי היחידה מסדר $n$ תמיד שווה ל-0 (המקדם של $z^{n-1}$ בפולינום $z^n-1$ הוא 0).
כלומר $\sum w_k = 0$.
הסכום המבוקש:
$S = \sum_{k=0}^{5} (1 + w_k) = \sum 1 + \sum w_k = 6 \cdot 1 + 0 = \mathbf{6}$.

פרק 2: גזירות, משוואות קושי-רימן ופונקציות הרמוניות

חלק 1: הסיכום המורחב (Theory Deep Dive)

1. גזירות (Differentiability): פונקציה $f(z)$ גזירה בנקודה $z_0$ אם קיים הגבול $f'(z_0) = \lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$. בניגוד למקרה הממשי, כאן הגבול חייב להיות זהה מכל כיוון במישור המרוכב.

2. משוואות קושי-רימן (C-R Equations): תהי $f(z) = u(x,y) + i v(x,y)$. תנאי הכרחי לגזירות בנקודה $(x_0, y_0)$ הוא קיום משוואות קושי-רימן: $$\mathbf{u_x = v_y}, \quad \mathbf{u_y = -v_x}$$ תנאי מספיק לגזירות: משוואות C-R מתקיימות בנקודה, והנגזרות החלקיות $u_x, u_y, v_x, v_y$ רציפות בסביבת הנקודה.

3. קושי-רימן בצורה פולרית (Polar C-R): אם $f(r, \theta) = u(r, \theta) + i v(r, \theta)$, המשוואות הן: $$\mathbf{u_r = \frac{1}{r} v_\theta}, \quad \mathbf{v_r = -\frac{1}{r} u_\theta}$$ והנגזרת: $f'(z) = e^{-i\theta}(u_r + i v_r)$.

4. אנליטיות (Analyticity): פונקציה נקראת אנליטית בנקודה $z_0$ אם היא גזירה ב-$z_0$ וגם בכל נקודה בתוך סביבה כלשהי של $z_0$. פונקציה אנליטית בכל המישור נקראת שלמה (Entire).

5. פונקציות הרמוניות וצמודות: פונקציה $u(x,y)$ היא הרמונית אם $\Delta u = u_{xx} + u_{yy} = 0$. אם $f = u + iv$ אנליטית, אז $u$ ו-$v$ הן הרמוניות צמודות. המשמעות הגיאומטרית היא שקווי הגובה שלהן ($u=c_1, v=c_2$) מאונכים זה לזה.

אלגוריתם: מציאת פונקציה אנליטית (שיטת מילן-תומסון)

זוהי שיטה מהירה למציאת $f(z)$ ישירות מתוך $u(x,y)$ ללא צורך באינטגרציה של $v$:

  1. חשב את הנגזרות החלקיות $u_x(x,y)$ ו-$u_y(x,y)$.
  2. נשתמש בנוסחה: $f'(z) = u_x(z,0) - i u_y(z,0)$.
  3. בצע אינטגרציה לפי $z$ כדי לקבל את $f(z) + iC$.
  4. (אם נתון $v$, התהליך דומה: $f'(z) = v_y(z,0) + i v_x(z,0)$).
דוגמה פתורה ברמת מבחן

שאלה: מצא פונקציה אנליטית $f(z)$ שחלקה הממשי הוא $u = e^x(x\cos y - y\sin y)$ ומתקיים $f(0)=0$.

פתרון בשיטת מילן-תומסון:

  1. נגזור לפי $x$: $u_x = e^x(x\cos y - y\sin y) + e^x(\cos y) = e^x(x\cos y - y\sin y + \cos y)$.
  2. נגזור לפי $y$: $u_y = e^x(-x\sin y - \sin y - y\cos y)$.
  3. נציב $x=z, y=0$:
    • $u_x(z,0) = e^z(z \cdot 1 - 0 \cdot 0 + 1) = e^z(z+1)$.
    • $u_y(z,0) = e^z(-z \cdot 0 - 0 - 0) = 0$.
  4. נרכיב את הנגזרת: $f'(z) = u_x(z,0) - i u_y(z,0) = (z+1)e^z$.
  5. אינטגרציה (לפי חלקים): $\int (z+1)e^z dz = (z+1)e^z - \int e^z dz = (z+1)e^z - e^z + C = ze^z + C$.
  6. נציב תנאי התחלה: $f(0) = 0 \cdot e^0 + C = 0 \Rightarrow C = 0$.

תשובה סופית: $f(z) = ze^z$.

חלק 2: תרגול פרימיום (Mastery Drill)

תרגיל 1

בדוק האם הפונקציה $f(z) = z \cdot Re(z)$ גזירה בראשית? האם היא גזירה בנקודות אחרות? האם היא אנליטית?

נכתוב את הפונקציה: $f(z) = (x+iy)x = x^2 + ixy$.
לכן $u = x^2, v = xy$.

בדיקת C-R:
$u_x = 2x, v_y = x$. נדרש $2x = x \Rightarrow \mathbf{x = 0}$.
$u_y = 0, v_x = y$. נדרש $0 = -y \Rightarrow \mathbf{y = 0}$.

מסקנה: משוואות C-R מתקיימות רק בנקודה $(0,0)$. מכיוון שהנגזרות החלקיות רציפות בכל מקום, הפונקציה גזירה בראשית בלבד. היא אינה גזירה בשום נקודה אחרת, ולכן אינה אנליטית באף מקום (כי אין לה סביבה של גזירות).

תרגיל 2 (קוטבי)

הוכח שהפונקציה $f(z) = \frac{1}{z^n}$ אנליטית בכל מקום פרט לראשית, באמצעות שימוש במשוואות C-R פולריות.

בהצגה פולרית: $z = re^{i\theta} \Rightarrow f(z) = (re^{i\theta})^{-n} = r^{-n} e^{-in\theta} = r^{-n}(\cos(-n\theta) + i\sin(-n\theta))$.
לכן: $u = r^{-n}\cos(n\theta)$ ו-$v = -r^{-n}\sin(n\theta)$.

גזירה:
$u_r = -nr^{-n-1}\cos(n\theta)$, $\frac{1}{r}v_\theta = \frac{1}{r}(-r^{-n} \cdot n \cos(n\theta)) = -nr^{-n-1}\cos(n\theta)$. (שווים!)
$v_r = nr^{-n-1}\sin(n\theta)$, $-\frac{1}{r}u_\theta = -\frac{1}{r}(r^{-n} \cdot (-n\sin(n\theta))) = nr^{-n-1}\sin(n\theta)$. (שווים!)

סיכום: המשוואות מתקיימות לכל $r \neq 0$. הפונקציה אנליטית בתחום $\mathbb{C} \setminus \{0\}$.

תרגיל 3

נתונה הפונקציה $u(x,y) = \sinh x \sin y$.
א. הראה כי $u$ הרמונית במישור כולו.
ב. מצא הרמונית צמודה $v$ כך ש-$v(0,0)=2$.
ג. בטא את $f=u+iv$ כפונקציה של $z$.

א. $u_x = \cosh x \sin y \Rightarrow u_{xx} = \sinh x \sin y$.
$u_y = \sinh x \cos y \Rightarrow u_{yy} = -\sinh x \sin y$.
$u_{xx} + u_{yy} = 0 \Rightarrow$ הרמונית.

ב. לפי C-R: $v_y = u_x = \cosh x \sin y \Rightarrow v = \int \cosh x \sin y dy = -\cosh x \cos y + h(x)$.
נגזור לפי $x$: $v_x = -\sinh x \cos y + h'(x)$. נשווה ל-$-u_y = -\sinh x \cos y$.
נקבל $h'(x) = 0 \Rightarrow h(x) = C$.
$v(0,0) = -\cosh(0)\cos(0) + C = -1 + C = 2 \Rightarrow C = 3$.
לכן $v = 3 - \cosh x \cos y$.

ג. נשתמש בזהויות: $f(z) = \sinh x \sin y + i(3 - \cosh x \cos y)$.
לפי מילן תומסון: $f'(z) = u_x(z,0) - i u_y(z,0) = \cosh z \sin(0) - i \sinh z \cos(0) = -i \sinh z$.
אינטגרל: $f(z) = -i \cosh z + C'$. בגלל $v(0,0)=2, u(0,0)=0$, נקבל $f(0)=2i$.
$-i \cosh(0) + C' = 2i \Rightarrow -i + C' = 2i \Rightarrow C' = 3i$.
לכן $\mathbf{f(z) = -i \cosh z + 3i}$.

תרגיל 4

תהי $f(z)$ אנליטית בתחום $D$. הוכח שאם $Re(f(z))$ קבוע ב-$D$, אז $f(z)$ קבועה ב-$D$.

אם $u(x,y) = C$, אז $u_x = 0$ ו-$u_y = 0$.
לפי משוואות קושי-רימן:
$v_y = u_x = 0$ ו-$v_x = -u_y = 0$.
מכיוון שהנגזרות החלקיות של $v$ הן 0 בכל התחום הקישור $D$, גם $v$ חייבת להיות קבועה.
מכיוון ש-$u$ ו-$v$ קבועות, $f = u+iv$ קבועה.

תרגיל 5

האם קיימת פונקציה אנליטית $f=u+iv$ כך ש-$u = x^2 + y^2$? נמק.

נגזור פעמיים:
$u_x = 2x \Rightarrow u_{xx} = 2$.
$u_y = 2y \Rightarrow u_{yy} = 2$.
לפלסיאן: $\Delta u = 2 + 2 = 4 \neq 0$.
מכיוון ש-$u$ אינה פונקציה הרמונית, היא לא יכולה להיות חלק ממשי של פונקציה אנליטית. תשובה: לא.

תרגיל 6

חשב את הנגזרת של $f(z) = \ln|z| + i \arg(z)$ בתחום $\mathbb{C} \setminus (-\infty, 0]$.

זוהי פונקציית הלוגריתם הראשי $\text{Log}(z)$.
בצורה פולרית: $u = \ln r, v = \theta$.
$u_r = 1/r, v_\theta = 1$. מתקיים $u_r = \frac{1}{r}v_\theta$.
$u_\theta = 0, v_r = 0$. מתקיים $v_r = -\frac{1}{r}u_\theta$.
הנגזרת: $f'(z) = e^{-i\theta}(u_r + i v_r) = e^{-i\theta}(1/r + 0) = \frac{1}{re^{i\theta}} = \mathbf{\frac{1}{z}}$.

תרגיל 7

מצא את הערך של הקבוע $a$ עבורו הפונקציה $v(x,y) = ax^2y - y^3$ היא הרמונית, וממצא לה צמודה $u$.

$v_x = 2axy \Rightarrow v_{xx} = 2ay$.
$v_y = ax^2 - 3y^2 \Rightarrow v_{yy} = -6y$.
נדרוש $2ay - 6y = 0 \Rightarrow \mathbf{a = 3}$.
כעת נחפש $u$ (נזכור $v$ הוא החלק המדומה):
$u_x = v_y = 3x^2 - 3y^2 \Rightarrow u = x^3 - 3xy^2 + h(y)$.
$u_y = -6xy + h'(y) = -v_x = -6xy \Rightarrow h'(y)=0$.
תשובה: $\mathbf{u = x^3 - 3xy^2 + C}$. (זוהי הפונקציה $f(z) = z^3$)

תרגיל 8 (ברמת מבחן)

תהי $f(z)$ אנליטית כך ש-$|f(z)|$ קבוע. הוכח ש-$f(z)$ קבועה. (רמז: השתמש ב-$u^2 + v^2 = C$).

אם $|f(z)|=0$, אז $f(z)=0$ והיא קבועה. נניח $|f(z)|^2 = u^2 + v^2 = C > 0$.
נגזור לפי $x$: $2uu_x + 2vv_x = 0 \Rightarrow uu_x + vv_x = 0$.
נגזור לפי $y$: $2uu_y + 2vv_y = 0$. נשתמש ב-C-R ($u_y=-v_x, v_y=u_x$):
$-uv_x + vu_x = 0$.
קיבלנו מערכת משוואות על $u_x, v_x$:
1) $u \cdot u_x + v \cdot v_x = 0$
2) $v \cdot u_x - u \cdot v_x = 0$
הדטרמיננטה היא $-u^2-v^2 = -C \neq 0$.
לכן הפתרון היחיד הוא $u_x = 0, v_x = 0$. באותו אופן $u_y=0, v_y=0$.
לכן הפונקציה קבועה.

תרגיל 9

הראה שהפונקציה $f(z) = \bar{z}^2$ אינה גזירה באף נקודה $z \neq 0$. האם היא גזירה ב-$z=0$?

$f(z) = (x-iy)^2 = x^2 - y^2 - 2ixy$.
$u = x^2 - y^2, \quad v = -2xy$.
C-R:
$u_x = 2x, \quad v_y = -2x$. שוויון רק אם $2x = -2x \Rightarrow \mathbf{x = 0}$.
$u_y = -2y, \quad v_x = -2y$. שוויון רק אם $-2y = 2y \Rightarrow \mathbf{y = 0}$.
המשוואות מתקיימות רק בראשית. מכיוון שהחלקיות רציפות, היא גזירה ב-$z=0$ בלבד.

תרגיל 10

מצא פונקציה שלמה $f(z)$ המקיימת $Re(f') = 3x^2 - 4y - 3y^2$ ו-$f(0)=i$.

נסמן $f'(z) = U + iV$. נתון $U = 3x^2 - 3y^2 - 4y$.
נשתמש במילן-תומסון על $f'(z)$ כדי למצוא את $f'(z)$ עצמה:
$U_x = 6x, \quad U_y = -6y - 4$.
הנגזרת של הפונקציה $f'$ (כלומר $f''$):
$f''(z) = U_x(z,0) - i U_y(z,0) = 6z - i(-4) = 6z + 4i$.
נבצע אינטגרציה למציאת $f'(z)$:
$f'(z) = 3z^2 + 4iz + C_1$.
נבצע אינטגרציה נוספת למציאת $f(z)$:
$f(z) = z^3 + 2iz^2 + C_1 z + C_2$.
מכיוון ש-$Re(f')$ נתון במדויק (ללא קבוע חופשי ב-$x,y$), הקבוע $C_1$ חייב להיות מדומה טהור, נניח $Ki$.
אבל $Re(3z^2 + 4iz) = Re(3(x+iy)^2 + 4i(x+iy)) = 3x^2-3y^2-4y$, שזה בדיוק $U$. לכן $C_1$ יכול להיות כל קבוע מדומה, אך בדרך כלל במבחן מצפים ל-$C_1=0$ אלא אם צוין אחרת.
נציב $f(0)=i \Rightarrow C_2 = i$.
תשובה: $\mathbf{f(z) = z^3 + 2iz^2 + i}$ (או בתוספת $Kiz$).

פרק 3: פונקציות אלמנטריות - אקספוננט, לוגריתם וחזקות

חלק 1: הסיכום המורחב (Elementary Functions)

1. האקספוננט המרוכב ($e^z$): מוגדר כ-$e^z = e^x(\cos y + i \sin y)$.

  • מחזוריות: $e^z$ היא פונקציה מחזורית עם מחזור $2\pi i$. כלומר $e^{z+2\pi i k} = e^z$.
  • תמונה: הפונקציה "מכסה" את כל המישור פרט ל-0 ($e^z \neq 0$ לכל $z$).

2. הלוגריתם המרוכב ($\log z$): הפתרון של $e^w = z$.

  • הגדרה כללית: $\log z = \ln|z| + i(\arg z + 2\pi k), \quad k \in \mathbb{Z}$. זוהי פונקציה רב-ערכית.
  • הענף הראשי ($\text{Log } z$): הערך בו הארגומנט בטווח $(-\pi, \pi]$. הוא אנליטי במישור כולו פרט לחתך לאורך ציר ה-$x$ השלילי ($(-\infty, 0]$).

3. פונקציות טריגונומטריות והיפרבוליות: $$\cos z = \frac{e^{iz} + e^{-iz}}{2}, \quad \sin z = \frac{e^{iz} - e^{-iz}}{2i}$$ $$\cosh z = \frac{e^z + e^{-z}}{2}, \quad \sinh z = \frac{e^z - e^{-z}}{2}$$ חשוב: במישור המרוכב, $\sin z$ ו-$\cos z$ אינן חסומות! (הן יכולות לשאוף לאינסוף ככל ש-$|y| \to \infty$).

4. חזקה כללית: מוגדרת באמצעות הלוגריתם: $z^c = e^{c \log z}$. זהו ביטוי רב-ערכי בדרך כלל.

אלגוריתם: פתרון משוואות עם פונקציות אלמנטריות

כדי לפתור משוואה מהצורה $f(z) = w$:

  1. משוואת אקספוננט: $e^z = w \Rightarrow z = \ln|w| + i(\text{Arg } w + 2\pi k)$.
  2. משוואה טריגונומטרית ($\sin z = w$):
    • המר לאקספוננטים: $\frac{e^{iz} - e^{-iz}}{2i} = w$.
    • סמן $t = e^{iz}$, תקבל משוואה ריבועית: $t^2 - 2iw t - 1 = 0$.
    • מצא את $t$, ואז פתור $iz = \log t$.
דוגמה פתורה: חזקות ורב-ערכיות

שאלה: מצא את כל הערכים של $i^{1-i}$. מהו הערך הראשי?

פתרון: לפי ההגדרה: $i^{1-i} = e^{(1-i)\log i}$.
נמצא את $\log i$: $|i|=1, \arg i = \pi/2 + 2\pi k$.
$\log i = \ln 1 + i(\pi/2 + 2\pi k) = i(\pi/2 + 2\pi k)$.
נכפיל במעריך: $(1-i) \cdot i(\pi/2 + 2\pi k) = (i - i^2)(\pi/2 + 2\pi k) = (1+i)(\pi/2 + 2\pi k)$.
לכן: $i^{1-i} = e^{(\pi/2 + 2\pi k) + i(\pi/2 + 2\pi k)} = e^{\pi/2 + 2\pi k} \cdot e^{i(\pi/2 + 2\pi k)}$.
נשתמש בזהות אוילר: $e^{i(\pi/2 + 2\pi k)} = \cos(\pi/2) + i\sin(\pi/2) = i$.
תשובה כללית: $i \cdot e^{\pi/2 + 2\pi k}$.
ערך ראשי ($k=0$): $i \cdot e^{\pi/2}$.

חלק 2: תרגול פרימיום (Mastery Drill)

תרגיל 1

מצא את כל פתרונות המשוואה $\sin z = 3$.

נציב $t=e^{iz}$. המשוואה הריבועית: $t^2 - 2i(3)t - 1 = 0 \Rightarrow t^2 - 6it - 1 = 0$.
לפי נוסחת השורשים: $t = \frac{6i \pm \sqrt{-36 + 4}}{2} = \frac{6i \pm \sqrt{-32}}{2} = \frac{6i \pm 4\sqrt{2}i}{2} = (3 \pm 2\sqrt{2})i$.
כעת נפתור $iz = \log t$:
אפשרות 1: $iz = \text{Log}((3+2\sqrt{2})i) + 2\pi k i = \ln(3+2\sqrt{2}) + i(\pi/2 + 2\pi k)$.
נחלק ב-$i$: $z = \pi/2 + 2\pi k - i\ln(3+2\sqrt{2})$.
אפשרות 2 (באופן דומה): $z = \pi/2 + 2\pi k - i\ln(3-2\sqrt{2})$.
תשובה: $z = 2\pi k + \pi/2 \pm i\ln(3+2\sqrt{2})$.

תרגיל 2

חשב את הערך הראשי של $(\sqrt{3}+i)^{12}$.

נעבור להצגה פולרית: $z = 2e^{i\pi/6}$.
לכן $z^{12} = (2e^{i\pi/6})^{12} = 2^{12} e^{i(12\pi/6)} = 4096 e^{2\pi i} = 4096 \cdot 1$.
תשובה: 4096.

תרגיל 3

מצא את כל הערכים של $\log(1-i)$.

$|1-i| = \sqrt{2}$. $\arg(1-i) = -\pi/4 + 2\pi k$.
$\log(1-i) = \ln\sqrt{2} + i(-\pi/4 + 2\pi k) = \frac{1}{2}\ln 2 + i(2k - 1/4)\pi$.

תרגיל 4

הוכח כי $\cos(iz) = \cosh(z)$ ו-$\sin(iz) = i\sinh(z)$.

לפי הגדרה: $\cos(iz) = \frac{e^{i(iz)} + e^{-i(iz)}}{2} = \frac{e^{-z} + e^{z}}{2} = \cosh z$.
$\sin(iz) = \frac{e^{i(iz)} - e^{-i(iz)}}{2i} = \frac{e^{-z} - e^{z}}{2i} = \frac{-(e^z - e^{-z})}{2i} = \frac{i(e^z - e^{-z})}{2} = i\sinh z$.

תרגיל 5

פתור את המשוואה $e^z = e^{i\pi}$.

לפי מחזוריות האקספוננט: $z = i\pi + 2\pi k i = (2k+1)\pi i$.

תרגיל 6

מצא את תמונת הקו הממשי $y=c$ תחת ההעתקה $f(z) = e^z$.

$z = x + ic \Rightarrow w = e^x \cdot e^{ic}$.
מכיוון ש-$x$ נע מ-$-\infty$ ל-$\infty$, הרדיוס $|w| = e^x$ נע מ-0 ל-$\infty$.
הארגומנט קבוע ושווה ל-$c$.
תשובה: קרן היוצאת מהראשית בזווית $c$ (לא כולל הראשית).

תרגיל 7

סווג את כל פתרונות המשוואה $\cos z = 0$. האם יש פתרונות שאינם ממשיים?

$\frac{e^{iz} + e^{-iz}}{2} = 0 \Rightarrow e^{iz} = -e^{-iz} \Rightarrow e^{2iz} = -1$.
$2iz = \log(-1) = i(\pi + 2\pi k) \Rightarrow z = \pi/2 + \pi k$.
מסקנה: כל הפתרונות הם מהצורה $\pi/2 + \pi k$. כולם מספרים ממשיים. אין פתרונות מרוכבים טהורים.

תרגיל 8

חשב את הערך הראשי של $(-1)^{-i}$.

$e^{-i \text{Log}(-1)} = e^{-i(i\pi)} = e^{\pi}$.
שים לב: חזקה מרוכבת של מספר שלילי יכולה לתת תוצאה ממשית!

תרגיל 9

מצא היכן הפונקציה $h(z) = \text{Log}(z^2+1)$ אינה אנליטית.

הפונקציה אינה אנליטית כאשר $z^2+1 \in (-\infty, 0]$.
נסמן $z^2+1 = -a$ (כאשר $a \ge 0$).
$z^2 = -a-1 \Rightarrow z = \pm i\sqrt{a+1}$.
מכיוון ש-$a \ge 0$, הביטוי $\sqrt{a+1}$ נע בטווח $[1, \infty)$.
תשובה: הפונקציה אינה אנליטית על הקרניים המדומות $\{ iy : y \ge 1 \}$ ו- $\{ iy : y \le -1 \}$.

תרגיל 10

נתונה הפונקציה $f(z) = \cosh^2 z - \sinh^2 z$. פשט אותה ככל הניתן.

זהה לזהות הפיתגוראית ההיפרבולית הממשית: $\cosh^2 z - \sinh^2 z = 1$ לכל $z \in \mathbb{C}$.

פרק 4: אינטגרלים קוויים ומשפטי קושי

חלק 1: הסיכום המורחב (Theory Deep Dive)

1. הגדרת האינטגרל הקווי: עבור מסלול $\gamma$ המוגדר ע"י $z(t) = x(t) + iy(t)$ בתחום $[a,b]$: $$\int_\gamma f(z) dz = \int_a^b f(z(t)) \cdot z'(t) \, dt$$ התוצאה תלויה בדרך אם הפונקציה אינה אנליטית, אך אינה תלויה בפרמטריזציה (כל עוד הכיוון נשמר).

2. משפט קושי-גורסה (Cauchy-Goursat): אם $f(z)$ אנליטית בתחום **פשוט קשר** $D$, אז לכל מסלול סגור $\gamma$ בתוכו: $$\oint_\gamma f(z) dz = 0$$ **הרחבה למסלולים מרובי קשר:** אם $f$ אנליטית בתחום שבין שתי עקומות סגורות $\gamma_1$ ו-$\gamma_2$ (כאשר $\gamma_2$ בתוך $\gamma_1$), אז האינטגרל עליהן באותו כיוון שווה.

3. אי-תלות במסלול ופונקציה קדומה: האינטגרל $\int_{z_1}^{z_2} f(z) dz$ אינו תלוי במסלול אם ורק אם קיימת ל-$f$ פונקציה קדומה $F$ (כך ש-$F'=f$) בתחום. במקרה זה: $$\int_{z_1}^{z_2} f(z) dz = F(z_2) - F(z_1)$$ זה נכון לכל פונקציה אנליטית בתחום פשוט קשר.

4. אי-שוויון ML (אומדן האינטגרל): אם $|f(z)| \le M$ לכל $z \in \gamma$, ואורך המסלול הוא $L$, אז: $$\left| \int_\gamma f(z) dz \right| \le M \cdot L$$ שימושי מאוד להוכחת התאפסות אינטגרלים כאשר רדיוס המסלול שואף לאינפור.

אלגוריתם: בחירת שיטה לחישוב אינטגרל
  1. **האם המסלול סגור?**
    • כן, והפונקציה אנליטית בפנים -> 0 (קושי-גורסה).
    • כן, ויש נקודות "בעייתיות" בפנים -> השתמש בנוסחת קושי (פרק 5) או משפט השאריות (פרק 7).
  2. **האם הפונקציה "פשוטה" (פולינום, $e^z$, $\sin z$)?** השתמש בפונקציה קדומה.
  3. **האם מופיעים צמוד ($\bar{z}$), חלק ממשי ($Re(z)$) או $|z|$?** חובה להשתמש בהגדרה (פרמטריזציה).
דוגמה פתורה: חישוב ישיר

שאלה: חשב את $\int_\gamma \bar{z} dz$ כאשר $\gamma$ הוא חצי מעגל היחידה העליון מהנקודה 1 לנקודה -1.

פתרון: 1. פרמטריזציה: $z = e^{it}$ עבור $t \in [0, \pi]$.
2. נגזרת: $dz = ie^{it} dt$.
3. הצבה: $\bar{z} = \overline{e^{it}} = e^{-it}$.
4. אינטגרל: $\int_0^\pi e^{-it} (ie^{it}) dt = \int_0^\pi i dt = [it]_0^\pi = \pi i$.
שים לב: לו הפונקציה הייתה $z$ (אנליטית), התוצאה הייתה $z^2/2|_1^{-1} = 0$.

חלק 2: תרגול פרימיום (Mastery Drill)

תרגיל 1

חשב את $\int_\gamma \pi e^{\pi \bar{z}} dz$ על ריבוע היחידה ($0 \to 1 \to 1+i \to i \to 0$).

$\int_0^1 \pi e^{\pi t} dt + \int_0^1 \pi e^{\pi(1-it)} idt + \int_1^0 \pi e^{\pi(t-i)} dt + \int_1^0 \pi e^{i\pi t} idt$.
לאחר חישוב כל הקטעים מתקבל: $2(e^\pi - 1)(i-1)$.
תרגיל 2

חשב את $\oint_\gamma \frac{1}{z} dz$ במסלול סגור המקיף את הראשית פעם אחת.

$z = Re^{it} \Rightarrow dz = iRe^{it}dt$.
$\int_0^{2\pi} \frac{1}{Re^{it}} iRe^{it} dt = 2\pi i$.
תרגיל 3

אומדן ML: הוכח ש-$|\int_{|z|=R} \frac{z+1}{z^4+1} dz| \to 0$ כש-$R \to \infty$.

$L = 2\pi R$. $M = \frac{R+1}{R^4-1}$.
$|I| \le \frac{2\pi R(R+1)}{R^4-1} \propto \frac{1}{R^2} \to 0$.
תרגיל 4

חשב את $\int_\gamma (z^2 + 2z) dz$ מ-0 ל-1+i.

קדומה: $z^3/3 + z^2$.
$(1+i)^3/3 + (1+i)^2 = \frac{2i-2}{3} + 2i = \frac{-2 + 8i}{3}$.
תרגיל 5

חשב $\oint_{|z|=1} \frac{1}{z^2} dz$.

ל-$z^{-2}$ יש קדומה $-z^{-1}$ בתחום המנוקב. לכן במעגל סגור האינטגרל הוא 0.
תרגיל 6

חשב את $\int_\gamma \text{Re}(z) dz$ על הקטע מ-0 ל-1+i.

$z(t)=t+it \Rightarrow dz = (1+i)dt$. $Re(z)=t$.
$\int_0^1 t(1+i)dt = (1+i)/2$.
תרגיל 7

חשב את $\int_\gamma |z|^2 dz$ מ-0 ל-1+i.

$z(t)=t+it \Rightarrow |z|^2 = 2t^2$.
$\int_0^1 2t^2(1+i)dt = \frac{2}{3}(1+i)$.
תרגיל 8

פרק 5: נוסחאות האינטגרל של קושי ותוצאותיהן

חלק 1: הסיכום המורחב (Theory Deep Dive)

1. נוסחת האינטגרל של קושי (CIF): אם $f(z)$ אנליטית בתחום פשוט קשר המכיל עקומה סגורה $\gamma$ ונקודה $z_0$ בתוכה, אז: $$f(z_0) = \frac{1}{2\pi i} \oint_\gamma \frac{f(z)}{z - z_0} dz$$ **משמעות:** ערך הפונקציה בנקודה פנימית נקבע לחלוטין ע"י ערכיה על השפה!

2. נוסחת הנגזרות הכללית: הפונקציה $f(z)$ גזירה אינסוף פעמים בתוך התחום, ונגזרותיה נתונות ע"י: $$f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_\gamma \frac{f(z)}{(z - z_0)^{n+1}} dz$$ זהו כלי חזק ביותר לחישוב אינטגרלים עם מכנים בחזקה גבוהה.

3. משפט ליוביל (Liouville's Theorem): פונקציה שלמה (אנליטית בכל המישור) שהיא **חסומה** ($|f(z)| \le M$) חייבת להיות **קבועה**. *יישום:* הוכחת המשפט היסודי של האלגברה.

4. עקרון המקסימום המודולרי: אם $f(z)$ אנליטית ולא קבועה בתחום חסום $D$, המקסימום של $|f(z)|$ מתקבל רק על **השפה** של $D$.

אלגוריתם: חישוב אינטגרלים באמצעות CIF
  1. זהה את הנקודות בהן המכנה מתאפס (נקודות סינגולריות).
  2. בדוק אילו מהנקודות נמצאות **בתוך** המסלול $\gamma$.
  3. עבור כל נקודה בפנים $z_0$:
    • בודד את הפונקציה "הטובה" (האנליטית) $f(z)$ כך שהאינטגרל יראה כמו $\int \frac{f(z)}{(z-z_0)^{k+1}}$.
    • גזור את $f(z)$ בדיוק $k$ פעמים.
    • הצב בנוסחה: $I = 2\pi i \frac{f^{(k)}(z_0)}{k!}$.
  4. אם יש מספר נקודות בפנים, פצל לשברים חלקיים או השתמש במספר מסלולים קטנים.
דוגמה פתורה: נגזרות גבוהות

שאלה: חשב את $I = \oint_{|z|=2} \frac{e^{2z}}{(z-1)^4} dz$.

פתרון: 1. הנקודה הבעייתית היא $z_0 = 1$. היא נמצאת בתוך המעגל $|z|=2$.
2. הפונקציה האנליטית היא $f(z) = e^{2z}$. החזקה במכנה היא 4, לכן נצטרך נגזרת שלישית ($n=3$).
3. נגזור: $f'(z)=2e^{2z}, f''(z)=4e^{2z}, f'''(z)=8e^{2z}$.
4. נציב $z=1$: $f'''(1) = 8e^2$.
5. לפי הנוסחה: $I = \frac{2\pi i}{3!} \cdot 8e^2 = \frac{2\pi i}{6} \cdot 8e^2 = \frac{8\pi e^2 i}{3}$.

פרק 6: טורי חזקות, טורי טיילור ולורן

חלק 1: הסיכום המורחב (Series and Convergence)

1. טורי חזקות: טור מהצורה $\sum a_n (z-z_0)^n$. רדיוס ההתכנסות $R$ נקבע לפי נוסחת קושי-הדמר: $1/R = \limsup \sqrt[n]{|a_n|}$.

  • בתוך העיגול $|z-z_0| < R$: הטור מתכנס בהחלט ובמידה שווה.
  • מחוץ לעיגול: הטור מתבדר.
  • הטור מייצג פונקציה אנליטית בתוך עיגול ההתכנסות.

2. טורי טיילור: אם $f(z)$ אנליטית בנקודה $z_0$, היא ניתנת לפיתוח יחיד לטור חזקות: $$f(z) = \sum_{n=0}^\infty \frac{f^{(n)}(z_0)}{n!} (z-z_0)^n$$ רדיוס ההתכנסות הוא המרחק מהנקודה $z_0$ לסינגולריות הקרובה ביותר.

3. טורי לורן (Laurent Series): אם $f(z)$ אנליטית בטבעת (Annulus) $r < |z-z_0| < R$, היא ניתנת לפיתוח: $$f(z)=\underbrace{\sum_{n=0}^\infty a_n (z-z_0)^n}_{\text{Analytic part}} + \underbrace{\sum_{n=1}^\infty \frac{b_n}{(z-z_0)^n}}_{\text{Principal part}}$$ טור לורן משמש לסיווג נקודות סינגולריות ולחישוב שאריות.

אלגוריתם: פיתוח לטור לורן בטבעות שונות

כאשר נתונה פונקציה רציונלית ונקודת סינגולריות (למשל $z=a$), ורוצים פיתוח סביב 0:

  1. **בחר את האיבר הדומיננטי:**
    • בטבעת "פנימית" ($|z| < |a|$): הוצא את הקבוע $a$ מחוץ לסוגריים כדי לקבל ביטוי מהצורה $\frac{1}{1 - (z/a)}$.
    • בטבעת "חיצונית" ($|z| > |a|$): הוצא את $z$ מחוץ לסוגריים כדי לקבל ביטוי מהצורה $\frac{1}{1 - (a/z)}$.
  2. השתמש בטור הגיאומטרי: $\frac{1}{1-q} = \sum_{n=0}^\infty q^n$ (מתכנס רק עבור $|q|<1$).< /li>
  3. שלב איברים באמצעות שברים חלקיים אם יש מספר קטבים.
דוגמה פתורה: שלוש טבעות שונות

שאלה: פתח את $f(z) = \frac{1}{(z-1)(z-2)}$ לטור לורן סביב $z=0$.

פתרון: נשתמש בשברים חלקיים: $f(z) = \frac{1}{z-2} - \frac{1}{z-1}$.
1. **טבעת $|z|<1$:** הטור מתכנס סביב הראשית (טור טיילור).
$\frac{1}{z-2} = \frac{-1}{2} \cdot \frac{1}{1-z/2} = -\sum \frac{z^n}{2^{n+1}}$.
$\frac{-1}{z-1} = \frac{1}{1-z} = \sum z^n$. סה"כ: $\sum (1 - 2^{-(n+1)})z^n$.
2. **טבעת $1<|z|<2$:** כאן $|1/z|<1$ ו-$|z/2|<1$.
$\frac{1}{z-1} = \frac{1}{z(1-1/z)} = \sum z^{-(n+1)}$. לכן: $-\sum 2^{-(n+1)}z^n - \sum z^{-(n+1)}$.
3. **טבעת $|z|>2$:** שניהם מפותחים עם $1/z$.

חלק 2: תרגול פרימיום (Mastery Drill)

תרגיל 1

מצא את רדיוס ההתכנסות של $\sum_{n=1}^\infty \frac{n!}{n^n} z^n$.

נשתמש במבחן המנה: $|\frac{a_{n+1}}{a_n}| = \frac{(n+1)!}{(n+1)^{n+1}} \cdot \frac{n^n}{n!} = \frac{n+1}{(n+1)^{n+1}} n^n = \frac{n^n}{(n+1)^n} = (\frac{1}{1+1/n})^n \to 1/e$.
לכן $R = e$.
תרגיל 2

פתח את $f(z) = \sin(z^2)$ לטור טיילור סביב $z=0$. מהו רדיוס ההתכנסות?

$\sin w = \sum \frac{(-1)^n w^{2n+1}}{(2n+1)!}$. נציב $w=z^2$:
$\sum_{n=0}^\infty \frac{(-1)^n z^{4n+2}}{(2n+1)!} = z^2 - \frac{z^6}{6} + \frac{z^{10}}{120} - \dots$
הרדיוס $R = \infty$ כי הפונקציה שלמה.
תרגיל 3

מצא פיתוח לורן של $f(z) = z^2 e^{1/z}$ סביב $z=0$. סווג את הסינגולריות.

$e^w = \sum \frac{w^n}{n!}$. נציב $w=1/z$:
$z^2 (1 + 1/z + \frac{1}{2z^2} + \frac{1}{6z^3} + \dots) = z^2 + z + \frac{1}{2} + \frac{1}{6z} + \frac{1}{24z^2} + \dots$
מכיוון שיש אינסוף איברים בחזקות שליליות, $z=0$ היא **סינגולריות עיקרית (Essential Singularity)**.
תרגיל 4

פתח את $f(z) = \frac{1}{z^2+1}$ לטור לורן בתחום $|z|>1$.

$\frac{1}{z^2(1+1/z^2)} = \frac{1}{z^2} \sum (-1/z^2)^n = \sum_{n=0}^\infty \frac{(-1)^n}{z^{2n+2}}$.
תרגיל 5

הוכח כי $\frac{1}{\cos z}$ אינה יכולה להתפתח לטור חזקות סביב 0 עם רדיוס התכנסות גדול מ-$\pi/2$.

חשב את $\oint_{|z|=1} z^2 \sin(1/z) dz$ באמצעות פיתוח לטור.

$\sin(1/z) = 1/z - 1/(6z^3) + 1/(120z^5) - \dots$

תרגיל 7

מצא פיתוח טיילור של $\text{Log}(z)$ סביב $z=1$ וקבע את רדיוס ההתכנסות.

תרגיל 8

נתון הטור $\sum \frac{(z-i)^n}{n^2}$. האם הטור מתכנס בנקודה $z=1+i$?

רדיוס ההתכנסות $R=1$. הטור על השפה הוא $\sum 1/n^2$, הוא מתכנס בהחלט.

תרגיל 9

מצא פיתוח לורן של $\frac{z}{(z-1)(z-3)}$ בטבעת $1 < |z| < 3$.

פרק 7: נקודות סינגולריות ומשפט השאריות

חלק 1: הסיכום המורחב (Singularities and Residues)

1. סיווג נקודות סינגולריות מבודדות: תהי $z_0$ נקודה מבודדת בה $f(z)$ אינה אנליטית. נסתכל על החלק העיקרי של טור לורן $\sum_{n=1}^\infty \frac{b_n}{(z-z_0)^n}$:

  • **סינגולריות סליקה (Removable):** אין חזקות שליליות ($b_n=0$ לכל $n$). הגבול $\lim_{z \to z_0} f(z)$ קיים וסופי.
  • **קוטב (Pole):** מספר סופי של חזקות שליליות. אם החזקה הגבוהה ביותר היא $m$, זהו קוטב מסדר $m$.
  • **סינגולריות עיקרית (Essential):** אינסוף חזקות שליליות. הגבול $\lim_{z \to z_0} f(z)$ לא קיים (משפט קסורטי-ויירשטראס).

2. הגדרת השארית (Residue): השארית של $f(z)$ בנקודה $z_0$ היא המקדם $b_1$ (מסומן כ-$a_{-1}$) בטור לורן: $$\text{Res}(f, z_0) = b_1$$

3. משפט השאריות (Residue Theorem): אם $f(z)$ אנליטית בתוך ועל עקומה סגורה $\gamma$ פרט למספר סופי של נקודות סינגולריות $z_1, \dots, z_n$ בתוכה, אז: $$\oint_\gamma f(z) dz = 2\pi i \sum_{k=1}^n \text{Res}(f, z_k)$$

אלגוריתם: שיטות לחישוב שאריות
  1. **קוטב פשוט ($m=1$):** $$\text{Res}(f, z_0) = \lim_{z \to z_0} (z-z_0) f(z)$$ אם $f(z) = \frac{P(z)}{Q(z)}$ ו-$Q'(z_0) \neq 0$: $\text{Res} = \frac{P(z_0)}{Q'(z_0)}$.
  2. **קוטב מסדר $m$:** $$\text{Res}(f, z_0) = \frac{1}{(m-1)!} \lim_{z \to z_0} \frac{d^{m-1}}{dz^{m-1}} \left[ (z-z_0)^m f(z) \right]$$
  3. **סינגולריות עיקרית:** חובה לפתח לטור לורן ולמצוא את המקדם של $1/(z-z_0)$.
  4. **שארית באינסוף:** $\text{Res}(f, \infty) = \text{Res}\left( -\frac{1}{z^2} f(1/z), 0 \right)$.
דוגמה פתורה: סכום שאריות

שאלה: חשב את $\oint_{|z|=3} \frac{e^z}{z^2-z} dz$.

פתרון: 1. נקודות סינגולריות: $z=0, z=1$. שתיהן בתוך המעגל $|z|=3$.
2. שתיהן קטבים פשוטים ($Q'(z) = 2z-1$).
3. שארית ב-0: $\frac{e^0}{2(0)-1} = \frac{1}{-1} = -1$.
4. שארית ב-1: $\frac{e^1}{2(1)-1} = \frac{e}{1} = e$.

חלק 2: תרגול פרימיום (Mastery Drill)

תרגיל 1

מצא את כל הנקודות הסינגולריות של $f(z) = \frac{1}{\sin(\pi/z)}$ וסווג אותן.

תרגיל 2

חשב את השארית של $f(z) = \frac{z^2}{(z-1)^2(z+2)}$ ב-$z=1$.

קוטב מסדר 2. נחשב $\lim_{z \to 1} \frac{d}{dz} [ (z-1)^2 f(z) ] = \lim_{z \to 1} \frac{d}{dz} [ \frac{z^2}{z+2} ]$.
הנגזרת: $\frac{2z(z+2) - z^2}{(z+2)^2} = \frac{z^2+4z}{(z+2)^2}$.
ב-$z=1$: $\frac{1+4}{3^2} = 5/9$.
תרגיל 3

חשב את $\oint_{|z|=2} \exp(1/z) z^3 dz$.

סינגולריות עיקרית ב-0. נפתח לטור:
$z^3 (1 + 1/z + \frac{1}{2z^2} + \frac{1}{6z^3} + \frac{1}{24z^4} + \dots) = z^3 + z^2 + \frac{z}{2} + \frac{1}{6} + \frac{1}{24z} + \dots$
המקדם של $1/z$ הוא $1/24$.
האינטגרל: $2\pi i / 24 = \pi i / 12$.
תרגיל 4

חשב את $\oint_{|z|=1} \frac{dz}{z^2 \sin z}$.

$z=0$ הוא קוטב מסדר 3 (שכן $\sin z = z - z^3/6 + \dots$ במכנה).
נפתח לטור או נשתמש בנוסחה לנגזרת שנייה. פיתוח טור קל יותר:
$1/(z^2(z - z^3/6 + \dots)) = 1/z^3 (1 - z^2/6)^{-1} = 1/z^3 (1 + z^2/6 + \dots) = 1/z^3 + 1/(6z) + \dots$
השארית היא $1/6$. האינטגרל $2\pi i / 6 = \pi i / 3$.
תרגיל 5

תרגיל 7

השארית (מקדם $z^{-1}$) היא $-1/3$.
תרגיל 8

חשב את $\oint_{|z|=1} z^n e^{2/z} dz$ עבור $n \in \mathbb{N}$.

כשנכפיל ב-$z^n$, נחפש איבר שבו $k = n+1$.
השארית היא $\frac{2^{n+1}}{(n+1)!}$. האינטגרל הוא $2\pi i \frac{2^{n+1}}{(n+1)!}$.
תרגיל 9

חשב $\oint_{|z|=10} \frac{dz}{z^2+z+1}$.

פרק 8: חישוב אינטגרלים ממשיים באמצעות שאריות

חלק 1: הסיכום המורחב (Real Integrals Classification)

סוג א: אינטגרלים טריגונומטריים $\int_0^{2\pi} R(\cos \theta, \sin \theta) d\theta$ מציבים $z = e^{i\theta}$. אז $\cos \theta = \frac{z+z^{-1}}{2}$, $\sin \theta = \frac{z-z^{-1}}{2i}$, ו-$d\theta = \frac{dz}{iz}$. האינטגרל הופך לאינטגרל מסלול על מעגל היחידה $|z|=1$.

סוג ב: אינטגרלים רציונליים $\int_{-\infty}^{\infty} \frac{P(x)}{Q(x)} dx$ כאשר $Q(x) \neq 0$ לכל $x$ ממשי והמעלה של $Q$ גדולה מהמעלה של $P$ ב-2 לפחות. האינטגרל שווה ל-$2\pi i \sum \text{Res}(f, z_k)$ עבור כל הקטבים $z_k$ בחצי המישור העליון ($Im(z)>0$).

סוג ג: אינטגרלים עם פונקציות טריגונומטריות (פורייה) $\int_{-\infty}^{\infty} f(x) e^{iax} dx$ משתמשים ב**למת ג'ורדן**: אם $|f(z)| \to 0$ כש-$|z| \to \infty$, אז האינטגרל על חצי המעגל העליון שואף ל-0 עבור $a>0$. האינטגרל הממשי שווה ל-$2\pi i \sum \text{Res}(f(z)e^{iaz}, z_k)$.

סוג ד: אינטגרלים עם קטבים על הציר הממשי (הערך העיקרי PV) אם יש קוטב פשוט ב-$x_0$ על ציר $x$, מבצעים "חריגה" (Indentation). תרומת החריגה היא $\pi i \cdot \text{Res}(f, x_0)$.

אלגוריתם: בחירת מסלול וחישוב
  1. זהה את סוג האינטגרל (טריגונומטרי, רציונלי, פורייה).
  2. מצא את כל הקטבים של הפונקציה המרוכבת המתאימה.
  3. סנן רק את הקטבים שנמצאים בתוך המסלול (לרוב חצי מישור עליון).
  4. חשב את השאריות בנקודות אלו.
  5. הכפל ב-$2\pi i$ (ובסוג ג' אל תשכח לקחת בסוף רק חלק ממשי או מדומה אם ביקשו $\cos$ או $\sin$).
דוגמה פתורה: סוג ג' (פורייה)

שאלה: חשב את $I = \int_{-\infty}^{\infty} \frac{\cos x}{x^2+a^2} dx$ ($a>0$).

פתרון: 1. נסתכל על $f(z) = \frac{e^{iz}}{z^2+a^2}$.
2. קטבים: $z = \pm ai$. רק $z = ai$ בחצי המישור העליון.
3. שארית ב-$ai$: $\text{Res} = \frac{e^{i(ai)}}{2(ai)} = \frac{e^{-a}}{2ai}$.
4. אינטגרל מרוכב: $2\pi i \frac{e^{-a}}{2ai} = \frac{\pi e^{-a}}{a}$.
5. מכיוון שהתוצאה ממשית, היא שווה ל-$I$ (החלק הממשי של האינטגרל המרוכב).
**תשובה:** $\frac{\pi}{a e^a}$.

פרק 9: עקרון הארגומנט ומשפט רושה

חלק 1: הסיכום המורחב (Argument Principle and Rouche)

1. עקרון הארגומנט: תהי $f(z)$ פונקציה מרומורפית (אנליטית פרט לקטבים) בתוך ועל עקומה סגורה $\gamma$. אם אין לה אפסים או קטבים על $\gamma$, אז: $$\frac{1}{2\pi i} \oint_\gamma \frac{f'(z)}{f(z)} dz = N(Z) - N(P)$$ כאשר $N(Z)$ הוא מספר האפסים (כולל ריבוי) ו-$N(P)$ הוא מספר הקטבים (כולל ריבוי) בתוך $\gamma$.
**משמעות גיאומטרית:** האינטגרל סופר כמה פעמים המסלול $f(\gamma)$ מקיף את הראשית.

2. משפט רושה (Rouche's Theorem): אם $f(z)$ ו-$g(z)$ אנליטיות בתוך ועל $\gamma$, ומתקיים **$|g(z)| < |f(z)|$** על **השפה** $\gamma$, אז ל-$f(z)$ ול-$f(z) + g(z)$ יש אותו מספר אפסים בתוך $\gamma$.
**יישום נפוץ:** מציאת מספר השורשים של פולינומים בתחומים מסוימים.

אלגוריתם: שימוש במשפט רושה למציאת שורשים
  1. **בחר את המסלול:** לרוב עיגול $|z|=R$.
  2. **פרק את הפונקציה:** כתוב את הפונקציה הנתונה כ-$f(z) + g(z)$.
  3. **בחר את האיבר הדומיננטי:** האיבר שיש לו הכי הרבה "כוח" על השפה יהיה $f(z)$.
  4. **בדוק את התנאי:** הוכח כי לכל $z$ על השפה $|g(z)| < |f(z)|$.
    טיפ: השתמש בגרסה ההפוכה של אי-שוויון המשולש: $|a+b| \ge ||a|-|b||$.
  5. **סיכום:** מספר האפסים של הפונקציה המקורית שווה למספר האפסים של $f(z)$ שבחרת (שהוא בדרך כלל איבר פשוט כמו $a z^n$).
דוגמה פתורה: מספר שורשים בטבעת

שאלה: כמה שורשים יש ל-$P(z) = z^4 + 3z + 1$ בטבעת $1 < |z| < 2$?

פתרון: 1. **נבדוק ב-$|z|<2$:** נבחר $f(z)=z^4$. על השפה $|z|=2$ מתקיים $|f(z)|=16$. השאר: $g(z)=3z+1 \Rightarrow |g(z)| \le 3(2)+1=7$. מכיוון ש-$7 < 16$, יש ל-$P(z)$ אותם מספר שורשים כמו ל-$z^4$, כלומר **4 שורשים** ב-$|z|<2$.
2. **נבדוק ב-$|z|<1$:** נבחר $f(z)=3z$. על השפה $|z|=1$ מתקיים $|f(z)|=3$. השאר: $g(z)=z^4+1 \Rightarrow |g(z)| \le 1^4+1=2$. מכיוון ש-$2 < 3$, יש ל-$P(z)$ אותם מספר שורשים כמו ל-$3z$, כלומר **שורש 1** ב-$|z|<1$.
3. **סיכום:** בטבעת יש $4 - 1 = 3$ שורשים.

חלק 2: תרגול פרימיום (Mastery Drill)

תרגיל 1

חשב את $\oint_{|z|=2} \frac{z+1}{z^2-1} dz$ באמצעות עקרון הארגומנט (אם אפשר) או משפט השאריות.

$g(z) = 3z^2 + 1 \Rightarrow |g(z)| \le 3(4) + 1 = 13$.
$13 < 32$, לכן יש 5 שורשים בתוך $|z|<2$. מכיוון שהפולינום ממעלה 5, כל שורשיו שם.
תרגיל 4

1) ב-$|z|<2$: $f=z^4$ ($16$), $g=-6z+3$ ($15$). $15<16 \Rightarrow 4$ שורשים.
2) ב-$|z|<1$: $f=-6z$ ($6$), $g=z^4+3$ ($4$). $4<6 \Rightarrow 1$ שורש.
תשובה: $4-1 = 3$.
תרגיל 5

השתמש במשפט רושה כדי להוכיח את **המשפט היסודי של האלגברה**.

יהי $P(z) = a_n z^n + \dots + a_0$. נבחר $f(z) = a_n z^n$ ו-$g(z) = a_{n-1}z^{n-1} + \dots + a_0$.
עבור $R$ מספיק גדול, $|f(z)| = |a_n| R^n$ יהיה גדול יותר מ-$|g(z)|$ על השפה $|z|=R$.
לכן ל-$P(z)$ יש $n$ שורשים (כמו ל-$z^n$).
תרגיל 6

מצא את מספר השורשים של $e^z - 3z^n = 0$ בתוך $|z|<1$ (עבור $n \ge 1$).

נבחר $f(z) = -3z^n$. על $|z|=1$, $|f(z)| = 3$.
$g(z) = e^z \Rightarrow |e^z| = e^{Re(z)} \le e^1 \approx 2.718$.
$2.718 < 3$, לכן יש $n$ שורשים.
תרגיל 7

האם למשוואה $z + e^{-z} = 2$ יש פתרון בחצי המישור הימני $Re(z)>0$?

נשתמש במסלול של חצי עיגול ענק מימין. על הציר המדומה ($z=iy$): $|iy + e^{-iy}| = |iy + \cos y - i \sin y| = \sqrt{\cos^2 y + (y-\sin y)^2}$.
זה תמיד $\ge 1$. בבחירה נכונה של $f(z)=z-2$ ניתן להראות שיש פתרון אחד.
תרגיל 8

כמה שורשים יש ל-$z^6 - 5z^2 + 10 = 0$ בטבעת $1 < |z| < 2$?

1) ב-$|z|<1$: $f=10$ (אין שורשים), $g=z^6-5z^2$ (מקס 6). $6<10 \Rightarrow 0$ שורשים.
2) ב-$|z|<2$: $f=z^6$ ($64$), $g=-5z^2+10$ ($30$). $30<64 \Rightarrow 6$ שורשים.
תשובה: 6 שורשים.
תרגיל 9

תהי $f(z)$ אנליטית ב-$|z| \le 1$ כך ש-$|f(z)| < 1$ על המעגל. הוכח כי יש ל-$f(z)$ בדיוק נקודת שבת אחת ($f(z)=z$) בתוך המעגל.

נגדיר $H(z) = f(z) - z$. נרצה לבדוק אפסים ל-$H$.
נבחר $F(z) = -z$, $G(z) = f(z)$. על השפה $|G(z)| = |f(z)| < 1$ ו-$|F(z)|=1$.
לכן $|G| < |F|$, ול-$f(z)-z$ יש אותו מספר אפסים כמו ל-$-z$, כלומר 1.
תרגיל 10

מה קורה אם האי שוויון $|g| < |f|$ הוא חלש ($\le$) או אם יש אפסים על השפה?

המשפט דורש אי-שוויון חזק על השפה. אם יש אפס על השפה, המשפט לא תקף ישירות (מספר האפסים בפנים עלול להשתנות בשינוי קטן של השפה).

פרק 10: פתרון משוואות דיפרנציאליות בעזרת טורים

חלק 1: הסיכום המורחב (Differential Equations and Power Series)

1. סיווג נקודות: עבור משוואה $P(x)y'' + Q(x)y' + R(x)y = 0$:

  • **נקודה רגולרית (Ordinary):** $P(x_0) \neq 0$. ניתן למצוא שני פתרונות בלתי תלויים כטורי טיילור $\sum a_n (x-x_0)^n$.
  • **נקודה סינגולרית רגולרית (Regular Singular Point):** $P(x_0) = 0$ אך הגבולות $p_0 = \lim_{x \to x_0} (x-x_0)\frac{Q(x)}{P(x)}$ ו-$q_0 = \lim_{x \to x_0} (x-x_0)^2\frac{R(x)}{P(x)}$ קיימים וסופיים.
  • **נקודה סינגולרית עיקרית:** נקודה שאינה רגולרית ואינה סינגולרית רגולרית.

2. שיטת פרובניוס (Frobenius Method): סביב נקודה סינגולרית רגולרית $x_0$, מחפשים פתרון מהצורה: $$y(x) = (x-x_0)^r \sum_{n=0}^\infty a_n (x-x_0)^n = \sum_{n=0}^\infty a_n (x-x_0)^{n+r}$$ הערך של $r$ נקבע ע"י **המשוואה האינדיסיאלית**: $r(r-1) + p_0 r + q_0 = 0$.

3. סוגי פתרונות (לפי שורשי האינדיסיאלית $r_1, r_2$):

  • אם $r_1 - r_2 \notin \mathbb{Z}$: קיימים שני פתרונות בצורת טורי פרובניוס.
  • אם $r_1 = r_2$: הפתרון השני יכיל איבר לוגריתמי $y_2 = y_1 \ln(x) + \dots$.
  • אם $r_1 - r_2 \in \mathbb{Z}$: הפתרון השני עשוי להכיל איבר לוגריתמי.

אלגוריתם: פתרון בשיטת הטורים
  1. בדוק את טיב הנקודה $x_0$ (לרוב $x_0=0$).
  2. הנח פתרון $y = \sum a_n x^{n+r}$ (אם רגולרית $r=0$).
  3. גזור ומצא ביטויים ל-$y'$ ו-$y''$.
  4. הצב במשוואה וסדר כך שכל האיברים יהיו תחת סכום אחד עם חזקה אחידה ($x^{n+k}$).
  5. השווה את מקדמי החזקה הנמוכה ביותר ל-0 למציאת המשוואה האינדיסיאלית (עבור $r$).
  6. מצא את **נוסחת הנסיגה** (Recurrence Relation) המקשרת בין $a_n$ ל-$a_{n-k}$.
  7. חשב את האיברים הראשונים של הטור עבור כל ערך של $r$.
דוגמה פתורה: שיטת הטורים (נקודה רגולרית)

שאלה: מצא פתרון בטור ל-$y'' + y = 0$ סביב $x=0$.

פתרון: 1. הנקודה $x=0$ רגולרית. נציב $y = \sum_{n=0}^\infty a_n x^n$.
2. משוואה: $\sum n(n-1)a_n x^{n-2} + \sum a_n x^n = 0$.
3. הזזת אינדקס בראשון: $\sum (n+2)(n+1)a_{n+2} x^n + \sum a_n x^n = 0$.
4. נוסחת נסיגה: $a_{n+2} = \frac{-a_n}{(n+2)(n+1)}$.
5. עבור $a_0$: $a_2 = -a_0/2, a_4 = a_0/24 \dots \Rightarrow a_{2k} = \frac{(-1)^k a_0}{(2k)!}$ (קוסינוס).
6. עבור $a_1$: $a_3 = -a_1/6, a_5 = a_1/120 \dots \Rightarrow a_{2k+1} = \frac{(-1)^k a_1}{(2k+1)!}$ (סינוס).

חלק 2: תרגול פרימיום (Mastery Drill)

תרגיל 1

מיין את הנקודה $x=0$ עבור המשוואות הבאות:
1. $x^2 y'' + xy' + (x^2-1)y = 0$ (משוואת בסל)
2. $x^3 y'' + y' + y = 0$

1. $P=x^2, Q=x, R=x^2-1$. גבולות $p_0 = \lim x(x/x^2) = 1, q_0 = \lim x^2(x^2-1)/x^2 = -1$. **סינגולרית רגולרית**.
2. $P=x^3, Q=1$. גבול $p_0 = \lim x(1/x^3) = \infty$. **סינגולרית עיקרית**.
תרגיל 2

מצא את המשוואה האינדיסיאלית ושורשיה עבור $3x^2 y'' + 2xy' + x^2 y = 0$ סביב $x=0$.

$p_0 = \lim x(2x/3x^2) = 2/3$. $q_0 = \lim x^2(x^2/3x^2) = 0$.
משוואה: $r(r-1) + \frac{2}{3}r + 0 = 0 \Rightarrow r^2 - \frac{1}{3}r = 0$.
שורשים: $r_1 = 1/3, r_2 = 0$.
תרגיל 3

עבור $y'' - xy' - y = 0$, מצא את נוסחת הנסיגה סביב $x=0$.

נציב טורי טיילור: $\sum (n+2)(n+1)a_{n+2} x^n - \sum n a_n x^n - \sum a_n x^n = 0$.
$(n+2)(n+1)a_{n+2} - (n+1)a_n = 0 \Rightarrow a_{n+2} = \frac{a_n}{n+2}$.
תרגיל 4

הוכח כי לפתרון בטור של $y'' - xy' - y = 0$ עם $y(0)=1, y'(0)=0$ יש צורה סגורה $y = e^{x^2/2}$.

מהתרגיל הקודם: $a_{k+2} = a_k/(k+2)$. עם $a_1=0$, כל האיברים האי-זוגיים הם 0.
עבור הזוגיים: $a_0=1, a_2=1/2, a_4=1/(2 \cdot 4), a_6=1/(2 \cdot 4 \cdot 6) \dots a_{2k} = \frac{1}{2^k k!}$.
הטור: $\sum \frac{(x^2/2)^k}{k!} = e^{x^2/2}$.
תרגיל 5

השתמש בשיטת פרובניוס למצוא את הפתרון הראשון של $2x^2 y'' - xy' + (1+x)y = 0$.

משוואה אינדיסיאלית: $2r(r-1) - r + 1 = 0 \Rightarrow 2r^2 - 3r + 1 = 0 \Rightarrow r_1=1, r_2=1/2$.
נוסחת נסיגה עבור $r=1$: $a_n = \frac{-a_{n-1}}{(n+1)(2n+1)}$.
תרגיל 6

משוואת לג'נדר: $(1-x^2)y'' - 2xy' + \alpha(\alpha+1)y = 0$. מצא נוסחת נסיגה ב-$x=0$.

$a_{n+2} = \frac{n(n+1) - \alpha(\alpha+1)}{(n+2)(n+1)} a_n = \frac{(n-\alpha)(n+\alpha+1)}{(n+2)(n+1)} a_n$.
מכאן רואים שאם $\alpha$ מספר שלם, הטור נקטע והופך לפולינום (פולינומי לג'נדר).
תרגיל 7

האם לכל משוואה לינארית מסדר 2 יש פתרון בטור חזקות סביב כל נקודה?

לא. בנקודה סינגולרית עיקרית (Irregular) לא תמיד קיים פתרון בצורת טור (גם לא פרובניוס).
תרגיל 8

מצא את רדיוס ההתכנסות המינימלי של פתרון בטור ל-$(x^2+4)y'' + y = 0$ סביב $x=0$.

הסינגולריות של המשוואה הן ב-$x = \pm 2i$.
רדיוס ההתכנסות הוא המרחק מהנקודה $0$ לסינגולריות הקרובה ביותר, לכן $R = |2i| = 2$.
תרגיל 9

עבור $x^2 y'' + xy' + x^2 y = 0$ (בסל מסדר 0), מהם שורשי המשוואה האינדיסיאלית?

$r(r-1) + r = 0 \Rightarrow r^2 = 0$. שורש כפול $r=0$.
זהו המקרה שבו הפתרון השני דורש איבר לוגריתמי.
תרגיל 10

מה קורה אם רדיוס ההתכנסות של הטור הוא 0?

זה אומר שהטור מתכנס רק בנקודת המרכז $x_0$, ולכן הוא לא מייצג פונקציה שימושית ואינו פתרון תקף למשוואה.

פרק 11: העתקות קונפורמיות וטרנספורמציית מוביוס

חלק 1: הסיכום המורחב (Conformal Mappings and Mobius)

1. העתקה קונפורמית: העתקה $f: D \to \mathbb{C}$ נקראת קונפורמית בנקודה $z_0$ אם היא משמרת זוויות בין עקומות (הן בגודל והן בכיוון).
**תנאי הכרחי ומספיק:** אם $f(z)$ אנליטית ב-$z_0$ ו-$f'(z_0) \neq 0$, אז $f$ קונפורמית ב-$z_0$.

2. טרנספורמציית מוביוס: העתקה מהצורה $f(z) = \frac{az+b}{cz+d}$ עם $ad-bc \neq 0$.

  • **תכונת המעגלים:** מוביוס מעבירה "מעגלים הכלליים" (מעגלים או ישרים) למעגלים הכלליים.
  • **העתקה של 3 נקודות:** קיים מוביוס יחיד המעביר שלוש נקודות שונות $(z_1, z_2, z_3)$ לשלוש נקודות שונות אחרות $(w_1, w_2, w_3)$.
  • **העתקות בסיסיות:**
    • הזזה: $z + b$
    • סיבוב ומתיחה: $az$
    • היפוך: $1/z$

3. משפט ההעתקה של רימן: כל תחום פשוט קשר שאינו כל המישור ניתן להעתקה קונפורמית וחד-חד-ערכית על עיגול היחידה.

אלגוריתם: בניית העתקות מוביוס ותחומים
  1. **מציאת העתקה ע"י 3 נקודות:** השתמש בנוסחת היחס הכפול (Cross-Ratio). $$\frac{w-w_1}{w-w_3} \cdot \frac{w_2-w_3}{w_2-w_1} = \frac{z-z_1}{z-z_3} \cdot \frac{z_2-z_3}{z_2-z_1}$$
  2. **העתקת חצי מישור לעיגול:** השתמש ב-$f(z) = e^{i\alpha} \frac{z-z_0}{z-\bar{z}_0}$ כאשר $Im(z_0)>0$. הנקודה $z_0$ עוברת למרכז העיגול (0).
  3. **העתקת עיגול לעיגול:** השתמש ב-$f(z) = e^{i\alpha} \frac{z-z_0}{1-\bar{z}_0 z}$ כאשר $|z_0| <1$.< /li>
דוגמה פתורה: שלבי העתקה

שאלה: העתק את הגיזרה $\{ z : |z|<1, Im(z)>0 \}$ לעיגול היחידה $|w|<1$.< /p>

פתרון: 1. **ראשית:** השתמש ב-$w_1 = \frac{z+1}{1-z}$. זה מעביר את חצי העיגול לרביע הראשון (ישרים ב-90 מעלות).
2. **ריבוע:** $w_2 = w_1^2$ מעביר את הרביע הראשון לחצי המישור העליון ($Im(w)>0$).
3. **מוביוס סופי:** $w = \frac{w_2-i}{w_2+i}$ מעביר את חצי המישור העליון לעיגול היחידה.

פתרון עבור $w$ נותן $w = \frac{z+i}{1+iz}$.

שאלה מסכמת 1

חשב את $\oint_{|z|=2} \frac{\sin z}{z^2(z+i)} dz$.

שארית ב-0 (קוטב מסדר 1 כי סינוס מתאפס ב-0) ושארית ב- מינוס $i$.
